# HAAVIK Photo · 可新增 AI 功能构思清单

> 现有架构已经把"加一种 AI 能力"做成了一套固定套路：在 `ai_ops.MODELS` 里加一项
> （指向一个 `.onnx` 文件 + 它服务的 `caps` + 推理参数）→ 写一个能力函数（输入 PIL 图、
> 输出 PIL 图，约定和 `matting()` 一致：RGB→[0,1]、固定 `input_size` 方图输入、模型
> 输出张量）→ 在 `image_tool.py` 的「AI」菜单加一行。只要能找到**输入/输出契约兼容**
> 的 ONNX，就能接进来。下面按这个套路，给出现在还能补的能力。

## 一、单点功能建议（功能名称 / 对应 AI 技术 / 实现价值）

| 功能名称 | 对应 AI 技术 / 模型类型 | 实现价值 |
| --- | --- | --- |
| **黑白照片上色** | 图像着色 CNN（DeOldify / ChromaGAN / InstColorization 的 ONNX 导出） | 给老照片、历史照一键自动上色，情怀拉满；很适合这个整蛊相册的"恶搞长辈老照片"场景。 |
| **人像美颜 / 磨皮** | 复用抠图得到的人像 alpha + 保边磨皮（引导滤波 / 轻量人脸解析 + DFB） | 自拍一键磨皮、祛痘、提亮肤色；**不需要新大模型**，靠现有抠图 mask 限定区域即可。 |
| **背景替换 / 虚拟背景** | 复用抠图 alpha + 合成（纯色 / 高斯模糊 / 用户自定义图） | 抠完图直接换背景，发朋友圈更自然；同样**不新增模型**，只是把 matting 的结果再合成一步。 |
| **老照片 / 模糊照修复** | 去模糊 + 通用复原（DeblurGAN-v2 / MPRNet / BSRGAN 的 ONNX） | 把拍糊、抖动的照片救回来，和现有的"超分"互补（超分管放大、这个管清晰）。 |
| **路人 / 物体消除** | 基于遮罩的修复扩散模型（LaMa / MAT / SD-Inpaint 的 ONNX） | 升级现有的 `inpaint`：去掉照片里乱入的路人、电线杆、水印；整蛊相册高频需求。 |
| **智能调色 / 自动白平衡** | 轻量图像到图像 CNN（HDRNet / DeepWhiteBalance / 曝光校正） | 一键纠正偏色、过曝、死黑；相册照片更"能看"，比手动拉曲线省事。 |
| **AI 艺术滤镜 / 风格迁移** | 快速风格迁移（AdaIN / 轻量 StyleNet 的 ONNX） | 照片一键变油画、动漫、水彩风；好玩、适合分享，模型小、CPU 能跑。 |
| **智能构图 / 一键裁剪推荐** | 显著性检测（IS-Net / U2Net，现有抠图同族模型可复用）+ 构图规则 | 自动推荐最佳裁剪框，懒人福音；能直接复用已有的显著性模型权重。 |
| **文档扫描增强** | 轻量文档矫正 + 去阴影（传统 CV + 轻 CNN） | 随手拍的文档/黑板变成"扫描件"效果（拉直、去阴影、增对比）。 |
| **图片文字识别（OCR）** | 轻量 OCR（PaddleOCR 的 ONNX 检测+识别） | 从截图/照片里提取文字，可顺带接"复制文字""翻译"；实用性强。 |
| **图像描述 / 自动打标签** | 轻量图文模型（BLIP-base / 小型 VLM 的 ONNX） | 自动给照片起名、打标签，方便整理整本相册；也能给"整蛊"自动配文案。 |
| **表情 / 年龄变化** | 人脸编辑 GAN（SimSwap / 局部 StyleGAN 的 ONNX） | 让人显老、变笑脸、换表情——纯整蛊向的"重口味"玩法，但模型偏重、需权衡体积。 |

## 二、可补充的功能模块（增强整体能力，不止单个模型）

- **AI 批量处理队列**：一次对整本相册按顺序跑多种 AI 能力（如批量上色 + 超分），后台
  线程跑、进度条显示，避免一张张点。
- **前后对比滑杆（Before/After）**：所有 AI 结果都支持"拖动对比原图/结果"，比现在的
  "直接替换"更直观，也方便用户决定要不要保留。
- **本地模型热切换**：同一能力允许多模型（如抠图在 RMBG-1.4 / BiRefNet 间选），菜单里
  多一个"用哪个模型"的小选项；`MODELS` 已经按能力聚合，加一个选择位即可。
- **AI 能力开关面板**：设置里列出已装模型、各能力开关、显存/磁盘占用，让用户知道自己
  机器上到底能跑啥（和现在"校验 AI 完整性"按钮是一脉相承的"透明化"思路）。
- **AI 结果缓存**：同一张图、同一参数不重复推理，直接读缓存；翻看相册时体验更顺。
- **失败可解释**：AI 跑挂时给出"是模型缺失 / 显存不够 / 图片格式不支持"的人话原因，
  而不是笼统报错（现在的 `_gate` 已经在做，可以再细化）。

## 三、落地优先级建议（个人项目、体积敏感）

1. **零新增模型就能做**：人像美颜、背景替换（都吃现有抠图 mask）——最划算，先上。
2. **小模型、高好玩**：黑白上色、艺术滤镜、智能构图——体积小、CPU 能跑，适合分发。
3. **中模型、高实用**：去模糊修复、路人消除（升级 inpaint）——按需再加。
4. **重模型、谨慎**：表情/年龄变化、VLM 描述——体积大，确认朋友机器扛得住再发。

> 注：所有新模型都要走和现在一样的"随 AI 组件包分发 + `ai_manifest.json` 登记 + 校验
> 完整性"流程，不进主程序 exe，保持主程序精简。模型来源优先用 `ai_model_prepare.py`
> 里已实测可达的镜像（hf-mirror.com / modelscope）。
